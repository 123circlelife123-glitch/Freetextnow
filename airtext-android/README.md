# Airtext (Android)
Offline phone-to-phone texting over Bluetooth / Wi-Fi Direct (Google Nearby Connections). No internet, SIM or plan.

## Get the APK for free (no Android Studio)
1. Create a free GitHub account, make a new repo, upload everything in this folder (keep the .github folder).
2. Open the repo's Actions tab, run "Build APK", then download the `airtext-apk` artifact (unzip it).
3. Copy app-debug.apk to each phone and install it (allow "install unknown apps").

Or open the folder in Android Studio and press Run.

## Use
Open Airtext on two phones, allow the permissions, tap the other phone's name, accept on both (check the code matches), then text.
Needs Android 7+ with Google Play services.
